# Staffing Plan — Bookmate

## 1. Project Period
October 12, 2026 to around mid-December 2026 (about 9 weeks in total).

| Sarkar Shuvo | 2577519 | Project Lead / Project Manager | Lead Developer (Android app, AI integration) |

## 3. Roles and Responsibilities

### Sarkar Shuvo — Project Lead and Lead Developer
- Plans and tracks the whole project; keeps the schedule and task list.
- Makes final technical decisions and resolves conflicts.
- Develops the Android app (Kotlin, Jetpack Compose) and integrates the AI features (recommendation assistant, summary chatbot).
- Reviews pull requests and manages the GitHub repository.
- Leads the SRS and Design documents.

### Karmaker Sudipta — Backend and Data Developer
- Designs the database and data structure (users, books, borrowing, reservations).
- Connects the app to book data sources (Google Books API, Open Library API).
- Prepares public-domain book text (Project Gutenberg) and splits it into chapters for the AI features.
- Builds the borrow/reserve logic and data handling.
- Co-develops app features with the lead.

### Sadik Md Nafis — QA and Documentation Lead
- Maintains document quality, formatting, and consistency across all documents.
- Writes and maintains the Requirements Traceability Matrix (RTM) with the lead.
- Prepares the test plan and test cases; tests each feature and reports bugs.
- Reviews UI screens for usability.
- Prepares the final report and presentation material with the team.

## 4. Shared Responsibilities (all members)
- Write and review project documents in their own area.
- Follow the Project Standards (Git rules, naming, code style).
- Join team meetings and update task status on time.
- Test their own work before submitting it.

## 5. Work Allocation by Phase

| Phase | Main documents / work | Lead person |
|---|---|---|
| Planning | System Request, Feasibility, Staffing Plan, Project Standards, Risk Assessment | Shuvo (all review; Nafis formats) |
| Analysis | SRS, RTM (first version) | Shuvo and Nafis |
| Design | UI design, architecture, database design | Shuvo (UI, architecture), Sudipta (database) |
| Implementation | App, backend/data, AI features | Shuvo (app, AI), Sudipta (backend, data) |
| Testing | Test plan, test cases, bug reports | Nafis |
| Final | Report, demo, presentation | Whole team |

## 6. Communication Plan
- Team meeting: once a week, with the day and time agreed by the team; extra short meetings when a deadline is close.
- Communication channel: a shared team chat group for daily updates.
- Task tracking: GitHub Issues / Projects board.
- Code and document changes go through GitHub branches and pull requests.

## 7. Staffing Risks and Handling
| Risk | Handling |
|---|---|
| Lead carries too much work (management plus development plus AI) | Sudipta co-develops app features; tasks are split into small issues early |
| A member is absent or busy (exams, other courses) | Every area has a backup person; documents are kept in the shared repo |
| Uneven skill levels (e.g., Android, Compose) | Pair work and short knowledge-sharing; start with small tasks |
